# Projects using Duel

These projects guard their performance with Duel: a pull request that
makes their code slower fails CI.

- [avdi/naught](https://github.com/avdi/naught): a toolkit for building
  Null Object classes in Ruby
- [bluepill-rb/bluepill](https://github.com/bluepill-rb/bluepill): a
  simple process monitoring tool
- [dkubb/equalizer](https://github.com/dkubb/equalizer): defines
  equality, equivalency and hash methods automatically
- [dkubb/memoizable](https://github.com/dkubb/memoizable): memoizes
  method return values
- [httprb/form_data](https://github.com/httprb/form_data): builds form
  data request bodies
- [httprb/http](https://github.com/httprb/http): a fast Ruby HTTP
  client with a chainable API, streaming support, and timeouts
- [laserlemon/simple_oauth](https://github.com/laserlemon/simple_oauth):
  builds and verifies OAuth headers
- [mbj/unparser](https://github.com/mbj/unparser): turns a Ruby AST into
  semantically equivalent Ruby source
- [omniauth/omniauth](https://github.com/omniauth/omniauth): flexible
  authentication with Rack middleware
- [omniauth/omniauth-oauth](https://github.com/omniauth/omniauth-oauth):
  a generic OAuth strategy for OmniAuth
- [omniauth/omniauth-oauth2](https://github.com/omniauth/omniauth-oauth2):
  an abstract OAuth2 strategy for OmniAuth
- [sferik/buftok](https://github.com/sferik/buftok): extracts
  token-delimited entities from a sequence of arbitrary inputs
- [sferik/multi_json](https://github.com/sferik/multi_json): a generic
  swappable back-end for JSON handling
- [sferik/multi_xml](https://github.com/sferik/multi_xml): a generic
  swappable back-end for XML parsing
- [sferik/robin](https://github.com/sferik/robin): fast, reliable
  background jobs for Ruby
- [simplecov-ruby/simplecov](https://github.com/simplecov-ruby/simplecov):
  code coverage for Ruby

## Add your project

Open a pull request that adds a line for your project to the list
above, in alphabetical order, in the same format: a link to its
repository, named by its owner and name, and what the project is, in a
few words. Any public repository counts, on GitHub, GitLab or anywhere
else.
